发布版 0.3.0 新增会话模型与推理强度选择、配置读回和实际请求头验证。原 0.2.0 是 0.1.1 的可移植打包。验证基线：DSH Desktop 0.2.0-rc.2。API 尚未稳定，后续 DSH 版本可能需要插件适配；安装包可迁移不表示所有版本自动兼容。

此前实际桌面验收：接口创建会话无需刷新可见；正常消息、工具执行及完整记录可见；模型提问可由 API 回答并继续写文件；取消真实运行生效；重启保留所有权与请求记录；适配 v4 tool 消息后过程输出可读。仅记录脱敏结论，原始会话与本机测试产物不公开。

本仓库 47 项可重跑行为测试覆盖原有会话/模型功能，以及插件清单、会话作用域、市场边界、版本固定、异步安装/取消、启用状态、重载后不确定操作和可恢复准备助手。测试使用 Host 行为替身，不调用模型，不单独证明真实桌面兼容。

真实权限授权请求尚未端到端触发，仅有替身测试。0.4.0 新增插件安装/启用接口；预设创作编辑仍不在接口范围，保留产品自身入口。模型选择适配当前安装的 Desktop 0.2.1-rc.1：调用 Host 本地 sessionController.agents 选择助手和 llm.resolveCallConfig，依赖版本相关的 Host 方法，缺失时返回 501；不会改写或补丁 Host。省略选择字段保留旧行为。实际桌面验证见下方 2026-10-18 记录。没有完整成本账单、完整卸载回滚、删除会话或多 Host 状态目录锁。

## 0.5.0 每轮复评

新增控制端 reassess.mjs 与技能轮次规则：首次执行、实现、debug、检查、验收均刷新事实，记录插件/模型/思考强度/预设四项理由。缺决策、无调整证据、目录不支持、违反显式约束或未结束执行会报告未决项。评估状态、执行就绪和语义验收分开；不执行建议、不调用模型。预设调整建议创建新会话并保留任务预算，不把历史工具调用或默认模型当作当前轮次执行证明。

47 项测试通过，包含真实 HTTP 桥接下的跨轮读回与状态变化，以及五阶段复评、约束继承、当前请求区间、冷会话和无副作用检查。本机运行的新助手通过已加载的 0.4.2 桌面后端完成两轮真实评估（8 次只读语义接口调用，其中 POST plan 不修改状态），插件清单、会话列表及默认模型均未变化，模型调用为 0。另实测中文路径 CLI、报告写入与跨轮文件关联。当前后端无需为该流程重启；0.5.0 安装包更新后的版本号在产品正常重载后体现。此项不声称进行了新的 DSH 模型执行或浏览器视觉验收。
