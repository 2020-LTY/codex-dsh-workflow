# 兼容和验证范围

发布版 0.2.0 是已有 0.1.1 插件的可移植打包，Host 控制逻辑未更改。验证基线：DSH Desktop 0.2.0-rc.2。API 尚未稳定，后续 DSH 版本可能需要插件适配；安装包可迁移不表示所有版本自动兼容。

此前实际桌面验收：接口创建会话无需刷新可见；正常消息、工具执行及完整记录可见；模型提问可由 API 回答并继续写文件；取消真实运行生效；重启保留所有权与请求记录；适配 v4 tool 消息后过程输出可读。仅记录脱敏结论，原始会话与本机测试产物不公开。

本仓库 15 项可重跑行为测试覆盖认证、浏览器拒绝、会话所有权、UUID、幂等重试、回执与结束判断、提问/授权及取消、卸载、持久化、输出限额和 v4 消息。测试使用 Host 行为替身，不调用模型，不证明真实桌面兼容。

真实权限授权请求尚未端到端触发，仅有替身测试。模型选择、插件安装、预设编辑不属于接口能力；沿用现有 DSH 设置。没有完整成本账单、自动回滚、删除会话或多 Host 状态目录锁。

升级后先验证 health，再运行一个微小任务，确认从创建开始可见、发送与结束、取消以及所需交互；不要把磁盘包版本当成已加载证明。
